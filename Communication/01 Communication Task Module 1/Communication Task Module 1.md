# Communication Task Module 1

## Subject-Verb Agreement / Subject-Verb Concord

### Simple Rule

| Subject  | Verb   |
|----------|--------|
| Singular | Singular |
| Plural   | Plural   |

- If the subject is **singular**, the verb should be **singular**.
- If the subject is **plural**, the verb should be **plural**.
