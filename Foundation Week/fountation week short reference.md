# 1. Understand Artificial Intelligence & Machine Learning

## 1.1 What is Artificial Intelligence?

Artificial Intelligence (AI) is the field of building computers and systems that can perform tasks that normally require human-like intelligence.

Examples:

* Understanding language
* Recognizing images
* Making decisions
* Solving problems
* Learning from information

## 1.2 What is Machine Learning?

Machine Learning (ML) is a way to build AI systems by training models to learn patterns from data.

Instead of writing every rule manually, we provide data and allow the model to learn patterns from it.

## 1.3 AI vs ML vs Deep Learning

**AI → ML → Deep Learning**

* **AI:** The broad field of building systems that can perform tasks requiring human-like intelligence.
* **ML:** A method of building AI systems that learn patterns from data.
* **Deep Learning:** A type of ML that uses neural networks with many layers to learn complex patterns.

## 1.4 Real-world Applications of AI Systems

AI is used in many areas, including:

* Virtual assistants
* Chatbots
* Image recognition
* Recommendation systems
* Fraud detection
* Autonomous systems
* Medical applications
* Language translation

## 1.5 Industry Use Cases of Machine Learning

Machine Learning is commonly used for:

* Sales prediction
* Demand forecasting
* Fraud detection
* Customer behavior prediction
* Product recommendations
* Disease prediction
* Spam detection

# 2. Understand the Machine Learning Lifecycle

## 2.1 Data Collection

Data collection is the process of gathering the data required to solve an ML problem.

## 2.2 Data Preparation

Data preparation involves cleaning, organizing, and transforming data so it can be used by an ML model.

## 2.3 Model Training

Model training is the process of teaching an ML model to find patterns in the training data.

## 2.4 Model Evaluation

Model evaluation checks how well the trained model performs on data it has not seen before.

## 2.5 Model Deployment

Model deployment means putting the trained model into a real application so users or other systems can use it.

## 2.6 Continuous Improvement of Models

After deployment, models can be monitored and improved using new data, updated training, or changes to the model.

# 3. Understand the Role of Data in ML

## 3.1 Structured vs Unstructured Data

**Structured data** has an organized format, such as rows and columns in a database.

**Unstructured data** does not have a fixed table-like structure, such as images, audio, video, and text.

## 3.2 Features and Labels

**Features** are the input information used by an ML model.

**Labels** are the expected answers or outcomes that the model tries to predict.

Example:

```text
Features:  House size, number of rooms, location
Label:     House price
```

## 3.3 Training and Testing Datasets

**Training data** is used to teach the model.

**Testing data** is used to check how well the model performs on unseen data.

## 3.4 Importance of Data Quality

Good-quality data helps an ML model produce better and more reliable results.

Poor-quality data can lead to incorrect or unreliable predictions.

## 3.5 Data-Driven Decision-Making

Data-driven decision-making means using data and analysis to make decisions instead of relying only on guesses or opinions.

# 11. Basic Statistics

## 11.1 Mean

Mean is the average of a set of numbers.

```text
Mean = Sum of all values / Number of values
```

Example:

```text
2, 4, 6

Mean = (2 + 4 + 6) / 3
     = 4
```

## 11.2 Median

Median is the middle value after the numbers are arranged in order.

Example:

```text
2, 4, 6, 8, 10

Median = 6
```

## 11.3 Mode

Mode is the value that occurs most frequently.

Example:

```text
2, 3, 3, 4, 5

Mode = 3
```

## 11.4 Variance

Variance measures how far the values are spread from the mean.

A higher variance means the values are more spread out.

## 11.5 Standard Deviation

Standard deviation measures the typical amount of variation or spread in a dataset.

A smaller standard deviation means the values are closer to the mean.

## 11.6 Range & Quartiles

**Range** is the difference between the maximum and minimum values.

```text
Range = Maximum - Minimum
```

**Quartiles** divide ordered data into four parts.

# 12. Basic Mathematics

## 12.1 Vectors

A vector is an ordered collection of numbers.

Example:

```text
[2, 4, 6]
```

Vectors are commonly used to represent data and mathematical quantities in ML.

## 12.2 Matrices

A matrix is a rectangular arrangement of numbers in rows and columns.

Example:

```text
[1  2]
[3  4]
```

## 12.3 Vector and Matrix Addition

Vectors or matrices can be added by adding their corresponding elements.

Example:

```text
[1, 2] + [3, 4] = [4, 6]
```

## 12.4 Vector and Matrix Multiplication

Multiplication is a mathematical operation used to combine vectors and matrices.

Matrix multiplication follows specific rules based on the dimensions of the matrices.

## 12.5 Basic Probability

Probability measures how likely an event is to happen.

```text
Probability = Number of favorable outcomes / Total possible outcomes
```

Probability ranges from `0` to `1`.

```text
0 = Impossible
1 = Certain
```

## 12.6 Independent Events

Two events are independent when one event does not affect the probability of the other.

Example:

```text
Rolling a die and flipping a coin
```

The result of the die does not affect the coin.

## 12.7 Dependent Events

Two events are dependent when one event affects the probability of the other.

Example:

Drawing two cards from a deck **without replacing the first card**. The first draw changes the probability of the second draw.
