# 2. Understand Control Flow
* **What are Conditional Statements?**<br>
  **Conditional statements** allow a program to make decisions by executing different blocks of code depending on whether a given condition evaluates to true or false.

  <details>
  <summary>Click for more</summary>
  
  1. **Keywords:** Handled in Python using the `if`, `elif` (else if), and `else` keywords.
  2. **Structure:** Only one block in an `if...elif...else` chain will execute per run.
  3. **Indentation:** Python uses whitespace indentation instead of curly braces to define code blocks.
  
  </details>

* **What are Nested Conditions?**<br>
  **Nested conditions** occur when you place an entire conditional statement entirely inside the block of another conditional statement.

  <details>
  <summary>Click for more</summary>
  
  1. **Syntax:** An inner `if` statement sits inside the indented block of an outer `if` statement.
  2. **Complexity:** Used to check multiple independent layers of criteria before executing an action.
  3. **Readability:** Deeply nesting multiple `if` blocks can make code confusing and difficult to follow.
  
  </details>

* **What are Loops?**<br>
  **Loops** are control structures that repeatedly run a specific block of code as long as a condition is met or a sequence has elements left.

  <details>
  <summary>Click for more</summary>
  
  1. **For Loops:** Best used to iterate over a predictable sequence like a list, tuple, or a specific range of values.
  2. **While Loops:** Keep running dynamically until a specified conditional statement becomes false.
  3. **Safety:** A `while` loop condition must eventually become false, or the program will lock up in an infinite loop.
  
  </details>

* **What are Control Statements?**<br>
  **Control statements** are specialized keywords used inside loops to instantly change or disrupt the standard sequence of iterations.

  <details>
  <summary>Click for more</summary>
  
  1. **Break:** Instantly terminates the loop iteration entirely and shifts execution to the code below the loop block.
  2. **Continue:** Aborts the remaining statements in the current iteration step and jumps directly to evaluating the next step.
  3. **Pass:** Acts purely as a syntax placeholder when Python requires a statement block but no logic is written yet.
  
  </details>

* **What is Logical Problem Solving?**<br>
  **Logical problem solving** is the mental approach of taking a complex operational goal and mapping it into sequential steps a computer can run.

  <details>
  <summary>Click for more</summary>
  
  1. **Flowcharts & Pseudocode:** Outlining code logic and edge-case boundaries in plain text before writing any raw script syntax.
  2. **Boolean Logic:** Using comparison operators combined with conditional statements to filter or validate user data accurately.
  3. **Edge Cases:** Accounting for unexpected data situations (e.g., negative numbers or empty collections) to prevent program crashes.
  
  </details>
