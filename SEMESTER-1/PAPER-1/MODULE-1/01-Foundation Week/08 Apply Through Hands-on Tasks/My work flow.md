# Install 
Run this Command on terminal:
`py -m pip install numpy pandas matplotlib scikit-learn`
> ![Check Python](18.png)<br>
> > 👆 Picture 18  (Installing numpy)

Then Verify using this command:<br> `py -c "import numpy, pandas, matplotlib, sklearn; print('All ML packages installed successfully')"`

**Create using this command:**<br>
`py -m venv .venv`<br>
**Then Activate it using this command:**<br>
`.venv\Scripts\activate`<br>
**You should then see:**<br>
`(.venv) C:\Users\Riyas\PythonStudy>`

**After that, verify:**<br>
`python --version`<br>
