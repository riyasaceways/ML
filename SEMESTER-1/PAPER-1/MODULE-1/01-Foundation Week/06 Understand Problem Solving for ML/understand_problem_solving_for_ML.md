# Understand Problem Solving for ML

### a. Thinking in Inputs and Outputs

Machine learning problems can be understood by looking at the **inputs** given to a system and the **outputs** we want it to produce. Inputs are the information the model receives, such as images, text, numbers, or other data. The output is the result we expect, such as a prediction, classification, or decision. Thinking this way helps clearly define what the ML system needs to do.

### b. Breaking Problems into Smaller Steps

ML problems can often be complicated, so it is useful to break them into smaller and more manageable steps. Instead of trying to solve the entire problem at once, we can identify what data is needed, how the data should be prepared, what the model should learn, and how its results will be evaluated. This makes the problem easier to understand, test, and improve.

### c. Understanding Patterns in Data

Machine learning depends on finding useful patterns in data. A model examines examples and tries to learn relationships that can help it make predictions or decisions about new data. For example, a model might discover patterns between customer behavior and purchases. Understanding what patterns exist, whether they are useful, and whether they generalize to new data is an important part of solving ML problems.

### d. Experimentation Mindset

Machine learning usually involves experimentation because the first approach may not produce good results. We can try different data preparation methods, model types, features, or settings and compare the results. Each experiment provides information about what works and what does not. The goal is not to expect the first attempt to be perfect, but to learn from each experiment and gradually improve the solution.

### e. Observation-Driven Problem Solving

Observation-driven problem solving means using evidence from data, experiments, and model behavior to guide decisions. Instead of assuming that a model is working correctly, we observe its predictions, errors, and performance and then investigate what is happening. These observations can reveal problems with the data, model, or approach and help us decide what should be changed next.
