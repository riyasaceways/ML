# Understand the Role of Data in ML

### a. Structured vs Unstructured Data

**Structured data** is data organized in a clear format, usually rows and columns, such as a spreadsheet containing customer names, ages, locations, and purchase amounts. **Unstructured data** does not follow a fixed table format. Examples include images, videos, audio recordings, documents, and social media posts. Machine learning systems can work with both types of data, although unstructured data often requires additional processing before it can be used effectively.

---

### b. Features and Labels

In machine learning, **features** are the pieces of information given to a model that help it make a prediction. For example, when predicting the price of a house, features could include its size, location, number of rooms, and age. A **label** is the expected answer the model is trying to predict, such as the house's actual price. Features provide the information, while the label represents the target answer.

---

### c. Training and Testing Datasets

A machine learning dataset is commonly divided into **training data** and **testing data**. The training dataset is used by the model to learn patterns and relationships from the available examples. The testing dataset is kept separate and is used later to check how well the trained model performs on data it has not seen before. This separation helps determine whether the model has actually learned useful patterns rather than simply memorizing the training examples.

---

### d. Importance of Data Quality

Data quality is important because a machine learning model can only learn from the data it receives. If the data contains incorrect values, missing information, duplicates, inconsistent formats, or strong biases, the model can learn incorrect patterns and produce unreliable results. Good-quality data should be accurate, relevant, consistent, and representative of the problem. In simple terms, poor-quality data can lead to poor predictions, even when the machine learning algorithm itself is well designed.

---

### e. Data-Driven Decision-Making

**Data-driven decision-making** means using collected and analyzed data to support decisions instead of relying only on assumptions, opinions, or guesses. Machine learning can analyze large amounts of data, identify patterns, make predictions, and provide useful information for decision-making. For example, a business could analyze customer behavior to predict which products are likely to be purchased. The final decision can then be supported by evidence from data rather than relying only on personal judgment.
